# X投稿文の作り方（Claude向け）

batでシーズン予測が終わると、デスクトップアプリにこの手順を読むよう依頼が届く。
その回に更新したリーグの投稿文を作る。各リーグ2本ずつ（J1: 優勝・降格、J2/J3: 昇格・降格）。

## 読むもの

1. `今回の材料.md` … 今回の数字と事実。確率の行・見出しはここにあるものだけを使う
2. `過去の投稿例.md` … 文体・長さ・行の組み立ての手本

## 1本の投稿の形

```
（見出し：材料の「見出し」をそのまま）
（確率の行：材料の候補を上から2〜3行、文字を一切変えずに）

（短評：2〜5行。解説を1〜2行含める）
```

- **確率の行は上から2〜3行だけ。** 途中を飛ばさない。4位以下のクラブの数字は画像に載っているので、文には書かない。浮いた文字数は解説に回す。
- 4位以下のクラブも、短評で話題にするのはよい（数字は付けず、材料の事実で書く）。
- **短評は材料に書いてある事実だけで書く。** 今節の勝敗、連勝・連敗・負けなし・勝ちなしの数、順位や勝点の位置、次の対戦（直接対決など）。材料にない情報（ケガ、監督、得点者、過去シーズンの話など）は書かない。
- 数字を書くときは材料の数字をそのまま使う（確率、連続記録、勝点）。
- 1行1クラブが基本。全体の傾向（「昇格圏クラブがそろって勝ち無し」など）を1行入れてもよい。
- 載せたクラブ全員に触れなくてよい。話題があるクラブを選ぶ。逆に、載せていないクラブの話題（好調な追い上げクラブなど）を1行入れてもよい。
- **解説①〜⑤（材料の「解説」の見出し）は毎回全部使わない。** その回に一番話題になるものを1〜2個だけ選び、短評の1〜2行に入れる。
- **解説の数字はすべてシミュレーションの予想値。** 断定せず、予想だと分かる言い方にする（「〜まで上がる予想」「〜前後と予想」「〜の見込み」）。「〜になる」「確定」とは書かない。
- 使い道（○の数字は必ず材料から取る。下は形だけの例）:
  - ① 試合の重み … 次節の直接対決や、勝敗で大きく動く試合の予告（「次節の○○との直接対決、負ければ降格確率は○%まで上がる予想」）
  - ② ライン予想 … 「自動昇格ラインは勝点○前後と予想」
  - ③ 残り日程 … 勝点が並ぶクラブの差（「○○は残りに上位との対戦が多い」）
  - ④ 実力と順位のギャップ … 巻き返し候補・踏ん張り（「実力は○番手、ここから浮上なるか」）
  - ⑤ 最終順位の幅 … 「最終順位は○〜○位のどこかになる見込み」
- 語尾は過去の投稿例に合わせる（体言止め、「〜に」「〜です」など、くだけすぎない）。
- 末尾にハッシュタグは付けない。

## 書き終えたら

1. 投稿文を `data/latest_post_text.json` に保存する。形式:

   ```json
   {
     "generated_at": "2026-11-22T19:30:00+09:00",
     "J1": {"champion": "投稿文", "relegation": "投稿文"},
     "J2": {"promotion": "投稿文", "relegation": "投稿文"},
     "J3": {"promotion": "投稿文", "relegation": "投稿文"}
   }
   ```

   今回更新していないリーグは、ファイルにある前回の文をそのまま残す。
2. チャットにも全部の投稿文を、1本ずつコードブロックで出す（そのままコピーできるように）。
3. git への commit / push は、頼まれたときだけ行う。
